### 2. VIVA AI Interview & Proctoring Platform

**React · Node.js · Express · Python · Flask · MongoDB · OpenCV · YOLO ·
MediaPipe**

An AI-assisted mock-interview platform designed to generate
role-specific questions from a candidate's résumé and support live
follow-up questions. Its computer-vision proctoring component is
described as detecting gaze, face orientation, additional people, and
hand-held objects, with transcripts and scores stored in MongoDB.


[View repository](https://github.com/afrazhussaincodes/AI-Interviewer)
